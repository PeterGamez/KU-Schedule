# 🗓️ KU Schedule (ตารางเรียน มก.)

**KU Schedule** คือส่วนขยายเบราว์เซอร์ (Google Chrome Extension) ที่ช่วยดึงและแสดงผลตารางเรียนของนิสิตมหาวิทยาลัยเกษตรศาสตร์ จากระบบ My KU สู่หน้าตารางเรียนที่อ่านง่าย สวยงาม ทันสมัย สะอาดตา และช่วยให้จัดตารางชีวิตการเรียนได้อย่างสะดวก รวดเร็ว ยิ่งขึ้น

> **An unofficial, client-side Chrome Extension for Kasetsart University students to fetch, view, and export class schedules effortlessly.**

---

## ✨ ฟีเจอร์เด่น (Key Features)

* 📅 **แสดงผลตารางเรียนแบบเต็มสัปดาห์ (Weekly Grid View)**  
  ครอบคลุมตั้งแต่เวลา 08:00 - 20:00 น. วันจันทร์ - วันอาทิตย์ แบ่งคอลัมน์และแถบสีตามวันตามมาตรฐาน ช่วยให้อ่านง่าย สบายตา
* 🔄 **ดึงตารางเรียนอัตโนมัติในคลิกเดียว (1-Click Sync)**  
  ดึงข้อมูลรายวิชา ห้องเรียน อาจารย์ผู้สอน และเวลาเรียนจากระบบ My KU โดยตรง ไม่ต้องเสียเวลากรอกวิชาเองทีละตัว
* 📚 **เลือกดูตามปีการศึกษาและภาคเรียน (Multi-Term Support)**  
  รองรับการเลือกปีการศึกษาและภาคเรียนย้อนหลังหรือล่วงหน้า (ภาคต้น / ภาคปลาย / ภาคฤดูร้อน)
* 🌐 **รองรับ 2 ภาษาเต็มรูปแบบ (Bilingual TH / EN)**  
  สลับการแสดงผลภาษาไทย (TH) และภาษาอังกฤษ (EN) ได้แบบเรียลไทม์ ทั้งชื่อวิชา ห้องเรียน ประเภทการเรียน (บรรยาย/ปฏิบัติ) และเมนูต่าง ๆ
* 📆 **ส่งออกเข้า Google Calendar (.ics)**  
  ส่งออกตารางเรียนเป็นไฟล์ iCalendar (`.ics`) พร้อมเปิดหน้าต่าง Google Calendar ให้นำเข้าได้ทันที พร้อมระบบเลือก **Format Template** ชื่อกิจกรรมตามความชอบ (เช่น แสดงรหัสวิชา, ชื่อวิชา, ตอนเรียน, ประเภทคาบ, ห้องเรียน) และกล่อง Preview ก่อนส่งออก
* 🖼️ **บันทึกรูปภาพความละเอียดสูง (Export PNG)**  
  เซฟตารางเรียนเป็นไฟล์ภาพ PNG คุณภาพสูง สำหรับตั้งเป็นภาพหน้าจอล็อก (Lock Screen) วอลเปเปอร์มือถือ/แท็บเล็ต/คอมพิวเตอร์ หรือแชร์ให้เพื่อนดูได้ทันที
* 💾 **เปิดดูแบบออฟไลน์ (Offline Cache Storage)**  
  บันทึกข้อมูลตารางเรียนและภาษาที่เลือกลงในพื้นที่จัดเก็บของเบราว์เซอร์ (Chrome Local Storage) เปิดขึ้นมาดูได้ทันทีแม้ไม่ได้เชื่อมต่ออินเทอร์เน็ต

## 🔒 ความเป็นส่วนตัวและความปลอดภัย 100% (Privacy & Security)

* **Client-Side 100%:** ประมวลผลและทำงานภายในเบราว์เซอร์ของผู้ใช้เท่านั้น
* **ไม่มีเซิร์ฟเวอร์ภายนอก (No External Backend):** ไม่มีการส่งข้อมูลตารางเรียน, ข้อมูลส่วนตัว หรือรหัสผ่านนิสิตออกไปยังภายนอก
* **ไร้การติดตาม (No Analytics & Tracking):** ไม่มีการเก็บข้อมูลสถิติหรือติดตามการใช้งานใด ๆ
* **ปลอดภัยและโปร่งใส:** โค้ดทั้งหมดเปิดเผยและไม่มีการบดบังโค้ด (Unobfuscated & Clean Architecture)

## 🚀 วิธีการใช้งาน (How to Use)

1. เข้าสู่ระบบเว็บไซต์ [https://my.ku.th](https://my.ku.th) บนแท็บใดก็ได้ใน Google Chrome
2. คลิกที่ไอคอน **KU Schedule** บนแถบส่วนขยายของเบราว์เซอร์ (มุมขวาบน)
3. เลือกปีการศึกษาและภาคเรียนที่ต้องการ แล้วกดปุ่ม **"ดึงตารางเรียน"**
4. ระบบจะโหลดข้อมูลตารางเรียนมาจัดแสดงผลให้อัตโนมัติ:
   * กด **"บันทึกรูป (PNG)"** เพื่อเซฟไฟล์ภาพตารางเรียน
   * กด **"ส่งออกปฏิทิน (.ics)"** เพื่อเลือกรูปแบบและนำเข้าสู่ Google Calendar
